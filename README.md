Official download portal for downloadxAI — free video downloader for Windows & macOS. This repo contains release binaries only; source code is not published here.

Download the latest version from the Releases page.

- Windows: `downloadxAI-Setup-<version>.exe`
- macOS (Apple Silicon): `downloadxAI-<version>-arm64.dmg`
- macOS (Intel): `downloadxAI-<version>-x64.dmg`

All macOS builds are unsigned — right-click the app → **Open** on first launch.
